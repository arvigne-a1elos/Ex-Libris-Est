# ESQUELETO DE GOVERNANÇA — A1ELOS

Este é o modelo em branco. NÃO EDITE ESTA PASTA.
Para criar um projeto novo, copie os três arquivos .md para uma pasta
com o nome do projeto e preencha os campos entre colchetes.

## Como criar um projeto novo

1. Crie uma pasta com o nome do projeto (ex.: projeto-2).
2. Copie ESTADO_ATUAL.md, DECISOES.md e COMO_RETOMAR.md para dentro dela.
3. Preencha todos os campos [ENTRE COLCHETES].
4. Adicione o projeto no INDICE.md da raiz.

## Os três arquivos e o que cada um faz

| Arquivo | Função | Quando atualizar |
|---------|--------|------------------|
| ESTADO_ATUAL.md | Onde estamos agora | A cada sessão |
| DECISOES.md | O que foi decidido e quando | Quando houver decisão nova |
| COMO_RETOMAR.md | Bloco de contexto para colar no início da sessão | Ao encerrar o dia |

## Regra de ouro

Se não está no repositório, não existe. A memória do projeto não pode
depender de uma conversa que será perdida.
